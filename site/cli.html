Add a component

Run this inside your React project — Next.js or Vite, it does not matter:

npx github:motyailyass/white-label-ui-kit list
npx github:motyailyass/white-label-ui-kit add button

The package is not on npm yet, so npx pulls the repository directly. Nothing is installed into your app; the command writes files and exits.

Because npm has no package name here, pin a ref when you want a stable copy:

npx github:motyailyass/white-label-ui-kit#main add button

What lands in your project

For add button, that is the component plus what it actually imports:

  • components/ui/button/ — component, CSS module, barrel.
  • components/ui/control-sizing.ts — the shared control-size contract.
  • components/icons/ — the Icon wrapper and registry.
  • lib/cn.ts — class name helper.
  • styles/tokens/ — written only if you do not have it yet.

Imports are rewritten to your real @/* alias when one is found in tsconfig.json or jsconfig.json. If none exists, the files keep @/ and the command tells you the paths entry to add.

Then it prints the two things a file copy cannot do for you: the token @import line for your global stylesheet, and the package install command for @hugeicons/react and @hugeicons/core-free-icons if they are missing.

Existing files are left alone. Tokens are never overwritten, because you will customize them.

Options

FlagWhat it does
--cwd <dir>Target another project instead of the current directory.
--dry-runPrint the file plan, write nothing.
--forceOverwrite files that already exist. Tokens still stay untouched.

Limits, stated plainly

  • Primitives only. A dashboard layout or a connected pattern needs the app shell, providers, and translations. The command tells you so and points at the starter instead of half-installing one.
  • One component at a time. Adding several is several commands.
  • No guided starter setup yet. Choosing framework, product, layout, and brand tokens in one flow is the next milestone.
  • No version pinning by package. Pin a git ref until a package is published.

Without the CLI

Copy a starter, or copy the pieces by hand. The starter path is still the fastest way to get a complete dashboard or website:

git clone https://github.com/motyailyass/white-label-ui-kit.git
cp -R white-label-ui-kit/typescript/nextjs/starterkit/dashboard ~/code/my-app
cd ~/code/my-app
pnpm install
pnpm dev

Full instructions: documentation quick start. The code is MIT licensed and has no runtime dependency on this repository.
