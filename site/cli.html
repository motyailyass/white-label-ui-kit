The CLI is not released.

There is no publishable command, package, or flag to copy from this page yet. Until a release is announced on GitHub, any command claiming to install this kit is unofficial.

Today: the manual path

The repository is complete and usable right now. Clone it and run the starter you need:

git clone https://github.com/motyailyass/white-label-ui-kit.git
cd white-label-ui-kit
pnpm install

cd typescript/nextjs/starterkit/dashboard
pnpm dev

To start a new product, copy the starter directory you want into your own repository. Keep the local preset, tokens, and components you need; delete the rest. The code is MIT licensed and has no runtime dependency on this repository.

Full instructions: documentation quick start.

What it will do

The intended flow is three choices, then source files written into your repository:

  1. Framework — Next.js App Router or Vite with React.
  2. Product — dashboard, website, or both, with a starting layout.
  3. Identity — brand accent, radius and density preset, and initial locale.

The result is the same source you would get from copying a starter: editable files, owned by you. The CLI removes the copy-and-delete step, not the ownership.

What it will not do

  • No runtime dependency and no locked component registry — generated code is your code.
  • No telemetry or account requirement for the free tier.
  • No hidden brand badge. Trademark and license notices still apply.
  • No Pro components. Premium offerings are delivered separately under commercial terms.

Status

The CLI has no release date. It ships after the free core is stable, so the generated output does not churn under early adopters. Command names and flags are not final, which is why none are published here.

Watch the repository for milestones — releases are announced there and nowhere else.
