# Vite Starter Kits

- **`starterkit/dashboard/`**: Minimal Vite portability reference validating framework-neutral Core UI (`Button`, `ThemeToggle`), semantic icons (`Icon`), providers (`AppProviders`, `ThemeProvider`, `I18nProvider`), connected patterns (`ThemeSwitcher`, `LanguageSwitcher`), self-hosted `@font-face` variable fonts (`Geist`, `Geist Mono`, `Noto Sans Arabic`), and shared + dashboard CSS tokens with zero Next.js dependencies.
- **`starterkit/website/`**: Planned (intentionally omitted until populated so the repository never advertises empty placeholder directories).
